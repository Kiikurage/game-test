# ボスの基本技 1・2・3（大上段斬り・薙ぎ払い・三連撃）

Issue #75（E5-3）の実装メモ。仕様の正は [vertical-slice.md](vertical-slice.md) の 6.3 / 6.4 / 5.1 節。AI 基盤とフレームワークは [boss-ai.md](boss-ai.md)。

## 構成

```
src/game/boss/moves/overhead.move.ts   技 1 大上段斬り
src/game/boss/moves/sweep.move.ts      技 2 薙ぎ払い
src/game/boss/moves/combo3.move.ts     技 3 三連撃
src/game/boss/bossTelegraph.system.ts  各段の頭に予備動作の SE（雑魚と同じ cue）を出す。bossTelegraphOf(info, phase) で段の種別を引ける
```

数値は仕様書の表どおり（P2 は `phase2Stages`）。ここに書くのは仕様から解釈した点だけ。

## 判断したこと

- **大上段斬りの判定**: 前方 60°・射程 4.5m を、扇形の頂点をボスの 1.5m 前に置いて 3.0m 伸ばす形（ボスの原点から最大 4.5m）で実現した。
  頂点より手前（斧の内側）は当たらず、前方ロールで潜り抜けられる（仕様「射程の内側に入る」）。ロールの無敵だけに頼らない。
- **薙ぎ払い**: 200°・射程 5.0m・床面 0.5〜2.5m（`sectorShape` の `yMin` / `yMax`）。バックステップ（2.0m）は 5.0m の内側に残るので、どのタイミングでも当たる。
  P2 の 1 発目と 2 発目の間は三連撃と同じ 8F、2 発目の最終硬直が P2 の 40F。2 発目の振りは逆方向（`SWEEP_SWING`、クリップは `Melee_Hook`）。
- **三連撃**: 射程 5.0m は全段に適用。2 段目の「逆方向」は振りの向き（`COMBO3_SWING`。演出・クリップのミラー用）で、判定の扇形はいずれも正面中心。
  1 段目をプレイヤーから見て左（ボスの右手側）へロールすると、1 段目 90°・2 段目 80° の外へ出られる。
- **追尾**: 大上段は F30 まで（P1 90°/s、P2 は 120°/s）。薙ぎ払いは発生の 12F 前まで（0.8 倍）、2 発目はほぼ向き固定。三連撃は 1 段が発生の 12F 前まで、2・3 段は短く弱い。
- **スーパーアーマー**: 大上段 P2 は F1〜F50、薙ぎ払い P2 は各発の予備動作〜持続。三連撃・P1 は無し。
- **連続攻撃の発生の下限**: ボスは 16F（`BOSS_MIN_FOLLOW_UP_STARTUP`）。三連撃 P2 の 2 段目（16F）を許すため。
- **接近**: 3 技とも歩きで射程に入り、足を止めてから予備動作に入る（大上段 3.2m・薙ぎ払い 3.0m・三連撃 3.0m で停止）。

## テレグラフの種別（5.1 節: 通常 = 白 / ガード不能・強攻撃 = 赤橙）

| 技・段 | 種別 | 理由 |
| --- | --- | --- |
| 大上段斬り | `heavy` | 発生 48 / 42F の強攻撃（ダメージ 110 / 120）。ガードは可能（スタミナ 60）なので `unblockable` ではない |
| 薙ぎ払い（P2 の 2 発目も） | `heavy` | 広範囲の強攻撃。P2 の 2 発目は連続攻撃なので `heavy` フラグ（34F 以上）は付けず、色だけ赤橙 |
| 三連撃 1・2 段 | `normal` | 発生 30 / 20F の素早い斬り。ガードして次を見る |
| 三連撃 3 段（突き） | `heavy` | 突進つきでダメージ 100 以上・発生 36 / 30F |

`unblockable` は今回の 3 技には無い（仕様でガード不能の技は無い）。武器の発光は雑魚と同じ仕組みで、ボスのモデル（#57）が入ってから `bossTelegraphOf` を描画側から引いてつなぐ。

## マーカー表（`bossClips.json`、仮置き）

| 動作 | クリップ | 備考 |
| --- | --- | --- |
| `boss.overhead.1` | `Sword_Heavy_Combo` の 1 打目 | クリップ内の当たりフレームは仮置き（F28） |
| `boss.sweep.1` | `Sword_Regular_B` + `_Rec` | 当たり F8 |
| `boss.sweep.2`（P2） | `Melee_Hook` + `_Rec` | 逆方向の振り。当たり F7 |
| `boss.combo3.1〜3` | `Sword_Regular_Combo`（90f）を段ごとに分割 | 範囲 0–22 / 22–39 / 39–89、当たり F15 / F32 / F57 |

フェーズ 2 の「アニメーション再生 1.15 倍」は、同じクリップ範囲・当たりフレームのまま P2 の発生・硬直から `playbackRate` が決まることで表れる（大上段 48 → 42F で 1.14 倍）。
実クリップに合わせた当たりフレームの確認は、ボスのモデルとアニメーション（#57）が入ってから。
