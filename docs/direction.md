# 基本方針

ステータス: **確定**（2026-10-09）。変更する場合はこの文書を更新し、理由を残す。

## 前提

- ブラウザで動作する 3D アクションゲーム
- エルデンリングライクな三人称視点アクション
- ボリュームより作り込みの完成度を優先する
- GitHub Pages で公開する

## 1. 最初のスコープ（垂直スライス）

小さいが最後まで作り込んだ 1 シーンを最初のゴールにする。

- 小さなフィールド 1 つ
- 雑魚敵 1〜2 種、ボス 1 体
- プレイヤーアクション: ロックオン、軽攻撃/強攻撃、回避（ローリング）、ガード、スタミナ、回復アイテム
- 死亡 → リスポーン（篝火相当の拠点）

## 2. 技術スタック

- TypeScript + Vite
- Three.js（WebGPURenderer、シェーダは TSL）
- 物理・衝突: Rapier（WASM）

### WebGPU 専用とする

WebGPU が使えない環境はサポートしない。WebGL2 フォールバックは提供しない。

- 理由: WebGL を考慮したシェーダの複雑化を避け、WebGPU の機能（コンピュートシェーダ等）を前提に設計するため。
- 起動時に `navigator.gpu` とアダプタ取得を確認し、使えなければ非対応メッセージを表示して終了する。
- Three.js の WebGPURenderer は WebGL2 へ自動フォールバックするため、これを無効化（強制しない設定）し、フォールバック経路は使わない。

## 3. 操作

- スマートフォン: 横画面固定。左半分を仮想スティック（移動）、右半分のドラッグでカメラ、右下にアクションボタン群。
  ロックオンはボタン 1 つでトグル、ターゲット切替は右側フリック。
- PC: キーボード/マウス、ゲームパッドも同時にサポートする。

## 4〜6. 性能目標・アセット・作り込みの重点

**[tech-direction.md](tech-direction.md)（技術・アート方針 v2、2026-10-11）で置き換えた。** 目標はコンシューマーゲームの傑作と並べて遜色ない一場面。モバイル（Xperia 1 V）60fps / PC 120fps。

変更の理由: 旧方針（ローポリ寄りのスタイライズド、モバイル 30fps / PC 60fps）は狙う水準が低く、オーナーの指示（2026-10-11）で再定義した。

旧方針から引き継ぐもの:

- 描画解像度の動的スケーリング。Xperia 1 V（4K）ではネイティブ解像度で描かない。
- 外部素材のライセンスと出典を `docs/` に記録する。
- オーナー決定（2026-10-09）: キャラクターは**等身寄り**（Quaternius Universal Base Characters + Universal Animation Library）。ライセンスは **CC0 のみ**（Mixamo・QAL は使わない）。取り込みは [assets.md](assets.md) の 7 章。
- 操作感・敵 AI とボス・見た目と演出・UI の**すべて**を作り込み対象とし、どれも妥協しない。
