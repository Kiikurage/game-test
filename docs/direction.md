# 基本方針

ステータス: **確定**（2026-10-09）。変更する場合はこの文書を更新し、理由を残す。

## 前提

- ブラウザで動作する 3D アクションゲーム
- エルデンリングライクな三人称視点アクション
- ボリュームより作り込みの完成度を優先する
- GitHub Pages で公開する

## 1. 最初のスコープ（垂直スライス）

小さいが最後まで作り込んだ 1 シーンを最初のゴールにする。

- 小さなフィールド 1 つ
- 雑魚敵 1〜2 種、ボス 1 体
- プレイヤーアクション: ロックオン、軽攻撃/強攻撃、回避（ローリング）、ガード、スタミナ、回復アイテム
- 死亡 → リスポーン（篝火相当の拠点）

## 2. 技術スタック

- TypeScript + Vite
- Three.js（WebGPURenderer、シェーダは TSL）
- 物理・衝突: Rapier（WASM）

### WebGPU 専用とする

WebGPU が使えない環境はサポートしない。WebGL2 フォールバックは提供しない。

- 理由: WebGL を考慮したシェーダの複雑化を避け、WebGPU の機能（コンピュートシェーダ等）を前提に設計するため。
- 起動時に `navigator.gpu` とアダプタ取得を確認し、使えなければ非対応メッセージを表示して終了する。
- Three.js の WebGPURenderer は WebGL2 へ自動フォールバックするため、これを無効化（強制しない設定）し、フォールバック経路は使わない。

## 3. 操作

- スマートフォン: 横画面固定。左半分を仮想スティック（移動）、右半分のドラッグでカメラ、右下にアクションボタン群。
  ロックオンはボタン 1 つでトグル、ターゲット切替は右側フリック。
- PC: キーボード/マウス、ゲームパッドも同時にサポートする。

## 4. パフォーマンス目標

| 環境 | 目標 |
| --- | --- |
| 基準スマートフォン: **Xperia 1 V**（Snapdragon 8 Gen 2 / Android / Chrome） | 30fps 安定 |
| PC | 60fps |

- 描画解像度の動的スケーリングを入れる。
- Xperia 1 V は 4K ディスプレイのため、ネイティブ解像度での描画は前提にしない（`devicePixelRatio` をそのまま使わず、内部解像度を上限付きで決める）。

## 5. アセット

- CC0 素材（Quaternius, Kenney, Poly Haven 等）、Mixamo のアニメーション、自作のいずれも可。
- スタイライズド寄り（ローポリ寄り＋ライティング・ポストエフェクトで雰囲気を作る）で統一感を優先する。
- 外部素材を使う場合はライセンスと出典を `docs/` に記録する。

### オーナー決定（2026-10-09）: 等身寄り・CC0 のみ

- キャラクターは**等身寄り**（デフォルメの強い KayKit 系ではなく）とし、**Quaternius の Universal Base Characters + Universal Animation Library（UAL / UAL2）** を採用する。
- ライセンスは **CC0 のみ**とする。Mixamo や Quaternius Asset License（QAL）など、再配布に制限のある素材は使わない（上の「Mixamo のアニメーション」は取り下げ）。
- 取り込みパイプラインと採用アセット・予算は [assets.md](assets.md) の 7 章を参照。

## 6. 作り込みの重点

以下の**すべて**を作り込み対象とする。いずれかを妥協して先に進むことはしない。

- 操作感: 入力応答、アニメーションキャンセル、ヒットストップ、カメラ
- 敵 AI とボスの攻撃パターン
- 見た目・演出
- UI
