# ボス技の判定フレームと実クリップの照合・予兆の武器発光・跳躍の押し出し

Issue #214 の実装メモ。仕様の正は [vertical-slice.md](vertical-slice.md) 6.3 節。技の構成は [boss-moves-basic.md](boss-moves-basic.md)（1〜3）/ [boss-moves-45.md](boss-moves-45.md)（4・5）、マーカー表の形式は [anim-event-markers.md](anim-event-markers.md)。

## 方針: ゲームのフレームデータは変えず、クリップの当て方を直す

仕様の発生・持続・硬直（= 回避窓。`dodgeSim` で検証済み）は**一切変えていない**。見た目と判定のずれは、`src/game/anim/data/bossClips.json` の
再生範囲（`clipRange`）・当たりフレーム（`clipHitFrame`）・先頭保持（`holdFrames`、新設）・戻りクリップの開始（`tail.startFrame`）で合わせた。
`dodgeSim` の回帰テスト（`dodgeSim.test.ts` / `basicMovesSim.test.ts` / `bossMoves45.test.ts`）は無変更で通り、各技の回避窓は 6.3 節の想定どおり。

## 計測方法

`animations.glb` の各クリップ（30fps キー）を three の `AnimationMixer` で 1F ずつ進め、斧の刃（ソケットの +Y 側 85%）・盾（`lowerarm_l`）・骨盤の
ワールド位置と 1F あたりの移動量を出した（ボスの 2.2 倍込み）。当たって見えるフレーム = 振り抜きの最速点・最下点・突きの伸びきり。
撮影は `?scene=test&bossmodel=1|2&action=<動作 ID>&sf=<段の F>&cam=three&dist=8`（実際の `BossAnimator` + マーカー表で段 F まで進めて固定。`&glow=normal|heavy` で予兆の発光）。

## 結果（クリップ内フレーム = 30fps）

「仮」は #75 / #76 の仮置き。

## `holdFrames`（マーカー表の追加フィールド）

`ClipEventEntry.holdFrames`（省略 = 0）: 動作の頭の N シミュレーションフレームは再生範囲の先頭のポーズを保ち、残りの `発生 − N` フレームでクリップの当たりまで進める。
クリップが「構えのない振り抜き」から始まる場合（盾打ち・跳躍）に、予備動作の間は構えを保つため。`clipHitFrame` があり、発生未満の整数。
`playbackRate` / `simFrameToClipTime` / `clipTimeToSimFrame` / `swingEndElapsed` に反映済み（hitStart は常に `clipHitFrame` の時刻）。

## 予兆の武器発光

`src/render/boss/bossWeaponGlow.ts`: `bossTelegraphOf`（段の `telegraph`）→ 立ち上がり・持続・脈動は雑魚と同じ `weaponTelegraphAmount`（8F で 0.5 → 1.0）に、ボス用の色の表を渡す。
`boss.view.ts` が毎フレーム `look.setWeaponTelegraph` へ（技の最中でなければ消す）。三連撃は段ごとに光り直す。

| 種別 | 色 | 強さ | 持続 | 使われる段 |
| --- | --- | --- | --- | --- |
| `normal` | 灰白の青み `0xd4e4ff` | 0.3 | 発生で消え始める（4F） | 三連撃 1・2 段、盾打ち |
| `heavy` | 氷の青 `0x4f8dff` | 1.0 | 持続の終わりまで | 大上段・薙ぎ払い・三連撃 3 段・盾打ち追撃・跳躍 |

**色の選択理由**: 既にある光は暖色ばかり（プレイヤーの溜め = 琥珀 `0xff7a00` → 金白 `0xfff0b8`、地面の予告と雑魚の強攻撃の縁 = 赤橙、フェーズ 2 の熾火 = 橙）。
ボスの予兆は**反対側の冷たい青白**にして、色相が 120° 以上離れるようにした（テスト `bossWeaponGlow.test.ts`）。ボスの眼の発光（`0x9fd8ff`）と同じ系統で、亡者の冷たい意志の光として一貫する。
深い熾火の赤は、地面の予告の赤橙・フェーズ 2 の橙の熾火と見分けにくいので避けた。色だけに頼らない: 通常は淡く短く、強攻撃は濃く持続の終わりまで。

盾打ち 1 段目（盾で打つ）は盾が光る（#225。盾は武器とは別のユニフォーム `setShieldTelegraph`。`applyUndeadLook(..., { shieldGlow: true })` がボスの盾だけを対象にする）。

**縁だけを光らせる（#225）**: 以前はフレネルで刃全体が一様な薄紫に染まりプラスチックに見えた。装備メッシュの頂点属性 `_EDGE`（`equipment.mjs` の `edgeness`: 0 = 面の中、1 = 輪郭・硬いエッジ。面は重心から輪郭へ補間される）を縁マスクにして、
`WeaponTelegraphStyle.edge = 1` のとき輪郭の細い帯だけが冷たい青に光り、刃の面は暗い金属のまま残る（視線の向きに依らない）。強攻撃（`heavy`）のピークだけ、輪郭から面へ淡いにじみ（`fill` = 0.55）が出る。`BOSS_GLOW_STYLE` が種別ごとの値。
`_EDGE` は VEC2（x のみ使用）: 1 成分の 16bit 属性は WebGPU の頂点フォーマットに無く、meshopt の量子化で描画に失敗する。

## 跳躍の着地の押し出し

`leapPushOut(boss, player)`（`leap.move.ts`）: 着地の瞬間（`boss-impact` が `bossSlam` を出す段 F73）に、プレイヤーがボスの体の中心から `LEAP_CLEARANCE`（体の半径 0.9 + カプセル半径 0.35 + 余裕 0.1 = 1.35m）未満なら、
ボス → プレイヤーの向きへ足りない分を押し出す（真上ならボスの向き = 飛んできた方向）。`Player.shove(dx, dz, frames)`（新設。状態は変えず、`slide` に 6 ステップで足す。壁の衝突は通常の移動と同じ）。
ロール中の無敵や被弾には影響しない。テスト: `moves/leapPushOut.test.ts`（純関数と、Game + 本物のプレイヤーで着地後に体の外へ出ている）。

## 武器の見た目の射程を判定に合わせる（#225）

UAL のクリップは人間サイズの剣の振りで、2.2 倍にしても刃先は判定の射程（4.5〜5.0m）に届かなかった。次の 3 つで合わせた。

1. **長柄の大斧**（`GreatAxe`）: 柄を `GREAT_AXE_REACH`（0.95m。ボスは 2.2 倍）伸ばし、石突きを短くした。全長 約 2.2m（ボスで約 4.8m。握りは石突きから 0.3m）。
2. **握りの向き**（`render/boss/bossAxeGrip.ts`）: 手から見た斧の向きを、構え（0。待機・移動。肩に担ぐ向き）と振り（1。剣のソケットと同じ向き）の間で動作ごとに選ぶ（`BossCharacter.setAxeGrip`、外挿は -0.6〜1.2）。
   動作中は右手だけで振る（フェーズ 2 の両手持ちは待機・移動のとき。剣の振りのクリップでは左手が柄と無関係に動き、両手の線に合わせると斧が後ろへ跳ねた）。値は表 `AXE_GRIP_BY_ACTION`（テストで全動作の存在を検証）。
3. **判定側を詰める**（回避窓・フレームは不変）: 大上段 4.5 → 4.2m（盾打ち追撃も同じ）、盾打ち 3.0 → 2.6m。薙ぎ払い 2 発目・回転斬り 2 回転目の `clipHitFrame` を 7 → 8、灰の波のクリップ範囲を大上段と同じ 17–30 に。

照合: `?scene=test&bossmodel=1|2&action=<ID>&sf=<hitStart>&cam=top|side&reach=<射程>`（`&reach=` で射程の円と ±0.4m の円、`&axegrip=` で握りを上書き、`&probe=1` で刃先の位置を `window.__bossProbe` / `__bossScan` に出す）。
刃先 = 斧の頭の頂点のうち、ボスの原点から水平に最も遠い点。hitStart（段 F）での刃先の距離:

| 動作 | 判定の先端 | 刃先 | 動作 | 判定の先端 | 刃先 |
| --- | --- | --- | --- | --- | --- |
| 大上段 P1/P2・盾打ち追撃 | 4.2 | 3.9 | 三連撃 2 段 | 5.0 | 4.8 |
| 薙ぎ払い 1 | 5.0 | 5.0 | 三連撃 3 段（突き） | 5.0 | 4.8 |
| 薙ぎ払い 2（P2） | 5.0 | 5.1 | 回転斬り 1 / 2 | 4.8 | 4.4 / 4.8 |
| 三連撃 1 段 | 5.0 | 5.2 | 盾打ち 1 段（盾の先） | 2.6 | 2.3 |

跳躍（着地の衝撃波）と灰の波（地面を走る線）は武器の先端が判定ではないので対象外（斧は構えのまま）。
回転斬りの軌跡（`bossSpin.view.ts` の輪、半径 3.5〜4.8m）は、刃先が約 4.4〜5.3m を通るので、そのまま斧頭の幅（約 1m）に重なる。変更なし。

## 未対応・メモ

- 構えの斧は肩に担ぐ向きで、頭が体の上 約 2m に出る（長柄のため）。
- 三連撃 1 段（斬り上げ）は、判定の持続の後半に刃先が頭上へ抜ける（クリップの動き）。
- `Jump_Start` の屈みの長い保持が不自然に見えないかは実機で要確認。
